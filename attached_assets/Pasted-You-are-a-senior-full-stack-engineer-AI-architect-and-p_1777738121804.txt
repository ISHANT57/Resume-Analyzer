# 📂 FEATURE IMPLEMENTATION

## 1. Resume Upload

* Accept PDF and DOCX
* Validate file type and size
* Store temporarily

---

## 2. Resume Parsing Engine

Extract structured fields:

* Name
* Email
* Phone
* Skills
* Projects
* Education
* Experience

Use:

* pdfplumber
* docx2txt

---

## 3. Section Detection Engine

Detect presence of:

* Summary
* Education
* Experience
* Skills
* Projects

Return missing sections.

---

## 4. Content Analysis Engine

Perform:

### Bullet Strength Analysis

* Detect weak verbs (developed, worked on)
* Check for impact statements

### Metrics Detection

* Count numbers (% / counts)
* If < 2 → weak content

### Repetition Detection

* Detect repeated words

### Grammar Check (basic or via AI)

---

## 5. ATS Simulation Engine

Simulate ATS behavior:

* Parsing success rate (% based on extracted text quality)
* Link validation (LinkedIn, GitHub)
* Email validation
* Formatting issues

Return:

* ATS Score (0–100)
* Parse Rate (%)

---

## 6. Scoring Engine

Calculate:

content_score = function(metrics, grammar, bullets)
section_score = function(section_presence)
ats_score = function(parse_rate, formatting)
tailoring_score = function(keyword_match)

final_score = weighted combination

---

## 7. Job Description Matching Engine

* Accept job description input
* Extract keywords
* Compare with resume text

Return:

* Match %
* Missing keywords
* Suggested skills

---

## 8. AI Enhancement Engine (Gemini API)

Use Gemini API to:

* Rewrite weak bullet points
* Suggest quantified achievements
* Improve summary
* Detect missing skills

Prompt must be structured and return JSON output.

---

## 9. History Tracking

Store:

* Resume
* Scores
* Analysis results

Display:

* Score trend graph
* Improvements over time
